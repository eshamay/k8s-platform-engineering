# Radius v0.62.0 was released on 2026-10-27 with breaking changes and one supported channel

## Scenario

A team evaluating Radius wants to know how fast it moves and how long a version stays supported. [[sources/research-gap-o6-platform-landscape]]

## What the repository shows

The Radius repository published v0.62.0 on 2026-10-27 (Apache-2.0), after release candidates rc.4 through rc.6 in the preceding two days. The `versions.yaml` file lists only channel 0.62 as supported and deprecates 0.61, 0.60, 0.59, and 0.58, which is a release roughly every month and a support window of one minor version. The 0.62.0 changelog lists breaking changes, among them "Remove legacy Azure Container Instances support". Both facts fit a project below 1.0. They do not show how many organizations run it, and the dossier found no named adopter. [[sources/research-gap-o6-platform-landscape]]
