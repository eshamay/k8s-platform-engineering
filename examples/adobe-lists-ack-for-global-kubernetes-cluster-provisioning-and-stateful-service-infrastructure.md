# Adobe lists ACK for global Kubernetes cluster provisioning and stateful service infrastructure

## Scenario

The AWS Controllers for Kubernetes community keeps an ADOPTERS file that calls itself "a self-reported list of users to help identify adoption and points of contact." Adobe is the first row the dossier read. [[sources/research-gap-g1-named-adopters]]

## What the entry says

Adobe's use is described as "Global Kubernetes cluster provisioning, stateful service infrastructure provisioning using multiple ACK controllers". No object count is given and the entry is undated. BT and Continuum Industries follow in the next two rows. The dossier read only the first three rows, so the rest of the list is not captured. URL: https://raw.githubusercontent.com/aws-controllers-k8s/community/main/ADOPTERS.md.

## How to read it

This is the first named production-style ACK adopter in the wiki that comes from ACK's own file. It also shows ACK used alongside several controllers at once, which matches the one-controller-per-AWS-service split described in [[entities/ack]].
